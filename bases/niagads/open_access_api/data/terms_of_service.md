# NIAGADS Open Access API — Terms of Use

The NIAGADS Open Access API provides programmatic access to publicly available genomic data, annotations, and research resources related to Alzheimer's disease and related dementias (AD/ADRD). The API is intended to support scientific research, education, data exploration, and the development of research tools and applications.

## Permitted Use

The API is freely accessible for research, educational, and computational purposes. Users may retrieve, analyze, integrate, and develop applications using data obtained through the API, subject to any applicable restrictions associated with individual datasets.

## Attribution and Citation

Users are encouraged to acknowledge NIAGADS Open Access and cite the original publications, datasets, and resources associated with the data they use. Where available, dataset-specific citation and attribution requirements should be followed.

## Responsible Use

Users are expected to access the API responsibly and avoid activities that compromise service availability or performance for others. NIAGADS reserves the right to implement rate limits or temporarily restrict access when necessary to maintain service stability and security.

## Data Use and Licensing

Data accessible through the API may originate from multiple contributing studies, repositories, and external resources. Individual datasets may be subject to separate licenses, attribution requirements, or usage conditions. Users are responsible for complying with those conditions.

The availability of data through the API does not supersede any applicable dataset-specific terms.

## Service Availability

NIAGADS may update API endpoints, data resources, response formats, or access policies as the platform evolves. Although efforts are made to maintain service reliability and compatibility, uninterrupted availability and backward compatibility are not guaranteed.

The API and its contents are not intended for clinical diagnosis, treatment decisions, or other direct medical applications.
